From first draft to better skill.

Three tools. One lifecycle.
01 / AUTHOR

Make the implicit explicit.

Work through an interview, scaffold the structure, and write a portable skill with authority scoped to the artifact you requested.

author-agent-skill
02 / REVIEW

Find the rough edges.

Run a read-only audit against a severity-based rubric. Get blockers, compatibility findings, and recommendations you can act on.

review-agent-skill
03 / CHECK

Keep the structure sound.

Validate portable metadata and high-confidence structural safety rules with a static checker you can run from your terminal.

npx skillwright <path>
A small start, a better skill

Meet your next workflow.

Bring Skillwright to your preferred harness, then invoke the authoring or review skill.

Read the installation guide ↗

Install the repository in Pi.

pi install git:github.com/jwmarshall/skillwright

Then run /skill:author-agent-skill [capability]
or /skill:review-agent-skill <path>.

Install Skillwright as a Claude Code plugin, then invoke either skill:

author-agent-skill
review-agent-skill

See the repository’s installation notes ↗

Make this repository’s .agents/skills/ directory available to your project, then invoke author-agent-skill or review-agent-skill.

New skills are written to .agents/skills/<name>/SKILL.md unless you choose another supported directory.

Checks are a beginning.

Static validation checks structure; it doesn’t prove behavioral correctness. Pair it with a skill review and real harness trials to see how your skill works in practice.
